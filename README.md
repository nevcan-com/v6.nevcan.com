# nevcan.com v6 (2021)

The sixth version of nevcan.com, made in June 2021: a one-page landing as a UI developer, "Who is
'Nevcan'?", with links to my developer profiles and a timeline of my work since 2006.

It was built but never published; nevcan.com stayed on v5 until v7 replaced it in 2022.

Online at **[v6.nevcan.com](https://v6.nevcan.com)** as part of the nevcan.com version archive,
hidden from search engines. The current site is [www.nevcan.com](https://www.nevcan.com).

## Stack

HTML and CSS, Bulma 0.9 from cdnjs, Rock Salt from Google Fonts. Hosted on GitHub Pages.
